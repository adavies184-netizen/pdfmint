# PDFMint Engine v1.16.2

## Editable, fidelity-preserving Word conversion

- Preserves non-text PDF content (lines, drawings, images and signatures) as
  a fixed page background.
- Recreates detected PDF text as positioned native Word text boxes so it can
  be selected and edited in DOCX and DOC.
- Retains the original PDF page dimensions and supports multi-page documents.

This replaces the image-only v1.16.1 Word export.
