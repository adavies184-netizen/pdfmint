PDFMint real-account launch setup
=================================

1. Create a Supabase project in the London/EU region you want to use.
2. Open SQL Editor and run database/supabase-schema.sql once.
3. In Project Settings > API, copy the Project URL and publishable/anon key into config.js.
   Never place the service-role key in this site package.
4. In Authentication > URL Configuration:
   - Site URL: your production PDFMint site URL
   - Redirect URL: https://YOUR-SITE/auth-callback.html
   - Redirect URL: https://YOUR-SITE/reset-password.html
5. In Authentication > Providers, enable Google and Apple and enter their client credentials.
6. Add the callback URL Supabase displays to the Google and Apple developer consoles.
7. Deploy the static-site package. Test create account, email confirmation, sign in, refresh,
   profile update, password reset, Google login, Apple login and sign out.

Sessions are issued and refreshed by Supabase Auth. User data is isolated with Postgres row-level
security, and the user-documents storage bucket is private by default.
